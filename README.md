## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload **all files and folders** from this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your invitation will be available at your GitHub Pages URL.

No build step, Node.js, or server is required — this is plain HTML/CSS/JavaScript.

## Customize
- Edit the event details in `index.html`.
- Replace `assets/ocean-baby-theme.jpg` with another image if desired.
- Change colors, typography, and animation timing in `style.css`.
- Change the countdown target time in `script.js`.

The RSVP button currently opens a celebratory confirmation popup. It can easily be connected to WhatsApp, Google Forms, or another RSVP service later.
